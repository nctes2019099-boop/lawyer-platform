تحميل المشروع

الحجم: 16 ميجابايت | صيغة: ZIP

خطوات التشغيل:

  1. فك ضغط الملف lawyer-platform.zip
  2. افتح Terminal/PowerShell في مجلد app
  3. شغّل: npm install
  4. شغّل: npx prisma generate
  5. شغّل: npx prisma db push
  6. شغّل: npx prisma db seed
  7. شغّل: npm start
  8. افتح المتصفح على http://localhost:3000
